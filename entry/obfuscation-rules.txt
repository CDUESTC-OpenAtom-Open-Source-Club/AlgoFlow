# Release obfuscation rules for the entry module (applied by build-profile.json5,
# buildOptionSet "release"). Debug builds are not obfuscated.
#
# Enabled: local names (always on once obfuscation is enabled), top-level
# names, and compaction.
#
# Deliberately NOT enabled:
# -enable-property-obfuscation  Property names are wire and storage formats:
#     sync payloads (sync.schema.json), AI requests/results (ai.schema.json),
#     RDB record_json, Preferences records and card binding data are built from
#     object literals and classes and then JSON.stringify'd. Renaming them would
#     break the shared contracts and make data written by an earlier build
#     unreadable. Enabling it needs a keep list derived from the schemas.
# -enable-export-obfuscation    Would also rename properties of exported classes.
# -enable-filename-obfuscation  Pages are loaded by path ("pages/Index" in
#     main_pages.json and router.pushUrl) and abilities/widget by srcEntry.
# -remove-log                   Logs are already redacted ([AlgoFlow] prefix,
#     safeLogValue) and are needed to diagnose release builds.
#
# Docs: https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/source-obfuscation-V5

-enable-toplevel-obfuscation
-compact
